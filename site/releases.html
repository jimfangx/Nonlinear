Release notes

Every release.

New features, improvements and fixes in each version of the macOS app. Downloads are on the GitHub releases page.

0.1.16November 23, 2026Latest

New

  • Add a repository's submodules to a view. When creating or editing a view, one click adds every submodule repository of a selected repository, including nested ones if you like.
  • AI chat on the Review tab. Open a chat panel about the whole PR from the toolbar, and pick up any earlier conversation about that PR, whether about specific lines or the whole thing. Conversations are saved on your device.

Improved

  • Turning on AI now covers every repository. Per-repository settings are only for keeping files out of prompts, or * to turn AI off for a repository.
  • Whole-PR summaries leave out files you've excluded from AI.

Fixed

  • AI summaries no longer come back blank when a model spends its whole budget reasoning: Nonlinear retries with more room, or tells you what happened.
  • PRs whose prerequisite is in a repository outside the view, and already merged, are no longer shown as “Blocked by chain”.
  • Repositories added to a view load their PRs right away, and grouping by repository lists the ones with no open PRs.
0.1.15November 23, 2026

New

  • Type any repository. Every place that asks for a repository suggests your starred and recent ones first, and searches GitHub when you type one Nonlinear hasn't seen yet.
  • Review progress in the inbox. PRs you've started reviewing show how much you've reviewed, with a ⟳ when new commits arrived since.

Improved

  • In side-by-side review, selecting lines selects whole rows, so marking them reviewed covers deleted and added lines alike. GitHub comments still go on the side you clicked.
  • The Review tab opens on your first starred repository.
  • Recent activity shows when changes happened on GitHub, not when Nonlinear noticed them.
  • macOS asks for Keychain access at most once per launch instead of repeatedly.

Fixed

  • Clicking a suggestion in the Git Graph's repository box now opens it.
  • The sync service URL and GitHub API base fields accept // while you type.
0.1.14November 23, 2026

New

  • Work in organizations that block OAuth apps. Some organizations only allow OAuth apps an owner has approved, so comments and reviews there used to fail even though your account had access. Add a fallback personal access token under Settings → GitHub access, and Nonlinear uses it for just those organizations while keeping your normal sign-in everywhere else.

Improved

  • When an organization blocks the app, the error explains both fixes: ask an owner to approve it, or add a fallback token.
  • Repeat reads in those organizations reuse cached answers, so they barely touch your GitHub rate limit.
0.1.13November 23, 2026

New

  • Private sync servers. If you run your own sync service, you can limit it to specific GitHub accounts. Anyone else is refused at sign-in, and removing someone also signs them out everywhere.

Improved

  • A sync server that doesn't accept your account now tells you so, in the app and in the browser tab, instead of leaving sign-in waiting.
  • Simpler local setup for developing against the sync service.
0.1.12November 22, 2026

New

  • Go to definition and find references. ⌘-click an identifier in a review, right-click it, or select it and press F12 / ⇧F12. Works in any language: the PR's changes, the full changed files (parsed for Scala, Python, Rust, TypeScript/JavaScript, C, C++ and Java), the rest of the repository, and a language server when one is set up.
  • Find in code. ⌘F after clicking the diff searches the code, with match case, whole word, regex, and a mode that searches every changed file.
  • Folder tree. Switch the changed-files list between a flat list and folders.

Improved

  • Delete local data now erases everything the app stores on your device, including repo mirrors and caches, and can also remove saved tokens and API keys.
  • The keyboard shortcuts page (⌘/) lists the new code navigation shortcuts.
0.1.6November 22, 2026

New

  • Share with MCP. On desktop, share a review selection with your local MCP clients for 30 minutes, then stop with one click.
  • Backup and restore. Export all your local data, including imported diffs, to one file and restore it on another machine.
  • Commit diffs. View a commit's changes from the Git Graph and from a PR's Commits tab.
  • Syntax highlighting in diffs for common languages.
  • Repository shortcuts. Star the repos you use most and jump between them from the Git Graph and Review.

Improved

  • Fields for linking PRs and repositories suggest ones you've used before.
0.1.4November 22, 2026

New

  • Safe mode. A top-bar switch that stops all GitHub writes. Changes are staged, and you review them one by one when you leave safe mode.
  • Ask AI about a line or a range of lines, from the right-click menu or the toolbar. You see the prompt and estimated cost first.
  • LGTM button that approves on GitHub in one click.
  • Show that you're reviewing. On your first review action, Nonlinear requests a review from you, so others see you've started. You can turn this off.
  • Release notes generator. Collects the PRs merged between each submodule's current and planned commit and groups them by label.
  • Color themes and an optional background image with a darkness slider.

Improved

  • Release pins show current → planned commit, each linked to GitHub, with a compare link.
  • The timeline has daily and weekly tick marks.
  • The PR stats box shows additions and deletions in color, with a proportional bar.
  • The Review tab separates the file list from the diff more clearly.
  • Delete private notes and discard drafts right where they appear.
  • ⌘P opens the command palette, like ⌘K.
  • j / k move between files in the Multi-Repo Diff viewer.
  • The sync status moved to the top bar.

Fixed

  • Clicking elsewhere now clears a line selection.
  • The timeline's Latest button only scrolls to today and no longer changes your pins.
0.1.0November 22, 2026First release
  • PR inbox across every repo you maintain, with editable categories, pinning and snoozing.
  • Cross-repo dependency chains from Depends-On: lines or the UI, with a managed chain block in each PR.
  • Submodule timeline and releases: pin commits, export a manifest, or open a draft PR that bumps every submodule.
  • Review built for big diffs, with progress that survives force-pushes, private notes and draft comments.
  • Kanban board, Multi-Repo Diff viewer and Git Graph.
  • Optional AI summaries with your own key or a local Claude Code or Codex CLI.
  • End-to-end-encrypted sync between devices.
