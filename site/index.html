Why Nonlinear

Multi-repo releases are a graph,
not a list.

GitHub shows you one repository at a time. Your release depends on twelve of them, nested three submodules deep. Nonlinear is built for how that work actually fits together.

No GitHub App

Nothing is installed into anyone's org. You sign in with your own account, and GitHub stays the source of truth for PRs, reviews and permissions.

Local-first

Notes, review progress, release plans and cards live on your devices. It works offline, and sync is end-to-end encrypted.

Submodule-native

Gitlinks, nested pins and cross-repo dependencies are built into the app, not bolted on afterwards. It was designed around the Chipyard ecosystem.

Dependency chains

Know exactly why a PR isn't ready to merge.

Write Depends-On: org/repo#123 in a PR body, or draw the chain yourself. Nonlinear builds the graph across repositories and gives you the reasons something is blocked, instead of a red X.

  • Cycles are rejected, with an explanation of where they come from
  • A managed chain block is kept in sync in every member PR
  • Every write is previewed, so nothing reaches GitHub without your OK

Review

Review 4,000-line diffs without losing your place.

A frontier rail tracks which hunks you've actually read. When the author force-pushes, your progress follows each hunk to its new position, and only the hunks that changed are marked stale.

  • Flags, private notes, and draft comments posted as one GitHub review
  • Go-to-definition and find-references through any LSP server
  • Step through a chain in order and expand submodule changes inline

And everything else

The rest of the workbench.

📥 Smart inbox

Categories you can edit, release lenses, pin and snooze, and a summary of what changed since you last looked.

🗂 Kanban board

Cards link PRs, releases and checklists. The same card can sit in different places on different boards, and the keyboard works everywhere.

📦 Multi-repo diff viewer

A 51 MB, 3,500-file JSON diff is indexed in about 280 ms and reopens instantly offline.

🌿 Git graph

A lane graph that reads from the GitHub API, your working tree, a partial mirror, or a remote machine over SSH.

✨ AI summaries, on your terms

Use your own API key or a local Claude Code or Codex CLI. You see every prompt first, and a hard budget cap stops spending.

♿ Accessible

Automated audits report zero WCAG 2.2 AA violations, in both light and dark themes.

Privacy & security

Your notes never leave your devices unencrypted.

Nonlinear is designed so that we couldn't read your data even if we wanted to.

🔐 End-to-end-encrypted sync

Data is encrypted with AES-GCM before it's uploaded. New devices pair by approval with a matching 6-digit code, or with a recovery key.

🪪 Minimal GitHub scope

OAuth only asks for public_repo, and over-scoped tokens are refused. In the browser, your token never reaches the page.

✋ Nothing sent without you

Chain blocks, labels, reviews and PRs are all previewed and need your confirmation. If you're offline, writes wait in a queue until you approve them.

🏠 Self-hostable

The sync service is a single Cloudflare Worker backed by D1. You can deploy your own in about five commands.
